# Site de Muay Thai — Professor Hendrew Jordão

Site estático gratuito para publicação no GitHub Pages.

## Abrir no computador

Abra o arquivo `index.html` com dois cliques. Para ver a melhor versão, publique no GitHub Pages.

## Publicar gratuitamente

1. Crie uma conta em https://github.com.
2. Clique em **New repository** e chame-o de `site-muay-thai`. Deixe-o como **Public**.
3. Envie todos os arquivos desta pasta para o novo repositório, incluindo a pasta `assets`.
4. No repositório, abra **Settings** → **Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**. Selecione a branch `main` e a pasta `/(root)`. Clique em **Save**.
6. Aguarde alguns minutos. O GitHub mostrará o endereço do site nessa mesma tela.

## Alterar informações depois

Abra `index.html`, troque o texto que deseja, salve e envie a versão nova para o repositório. O site será atualizado automaticamente.
